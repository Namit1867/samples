# Tab B

- **Catch regressions early** — tests surface broken behaviour the moment a change is introduced, before it reaches production.
- **Document expected behaviour** — a well-written test suite serves as living documentation that explains what the code is supposed to do.
- **Enable confident refactoring** — with solid test coverage, developers can restructure code knowing that failures will immediately flag unintended side effects.

## Extra

- **Reduce debugging time** — automated tests narrow down the source of a failure quickly, cutting the time spent diagnosing issues.
- **Increase team confidence** — a reliable test suite gives the whole team assurance that new contributions don't silently break existing functionality.
